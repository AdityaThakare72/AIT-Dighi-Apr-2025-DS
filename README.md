# AIT-Dighi-Apr-2025-DS

Data science and ML code from the AIT Dighi workshop, April 2025 (five days).

## Contents

- `day1`: NumPy and Pandas
- `day2`: data visualization and data cleaning
- `day3`: encoding, feature scaling, linear and logistic regression
- `day4`: decision trees, KNN and random forest
- `day5`: resampling, feature selection, hyperparameter tuning and project development

Open the notebooks in Jupyter or Google Colab. The csv, json and xlsx files next to them are the datasets the notebooks use.
